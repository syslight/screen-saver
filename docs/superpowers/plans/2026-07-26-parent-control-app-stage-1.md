# 家长控制端阶段 1

## 目标

建立独立 Android 家长 App，让家长通过一次服务器配置和一次身份认证控制客厅智能屏，不要求理解家庭 Agent 与相框控制服务的端口差异。

## 范围

1. 单一家庭服务器主机地址派生 8790 Agent HTTP 与 8780 智能屏 WS。
2. 支持空库首次初始化家庭、家长登录、会话安全保存和退出撤销。
3. 展示播放端在线状态、当前照片、天气、语音、NAS 与音量。
4. 支持上一张、下一张、刷新天气和调节播报音量，断线自动重连。
5. 配置 Home Agent 用户级常驻服务，局域网监听 `0.0.0.0:8790`。

## 边界

- 当前智能屏 8780 尚无独立 bearer 校验；App 以家长登录作为 UI 门禁，但部署仍限可信家庭 Wi-Fi。
- 本阶段不复制家长作业 Web 的全部功能；作业、人物身份确认、设备管理将在后续控制端阶段逐步原生化。
- 不把 8780/8790 暴露公网；远程访问前统一加 HTTPS/WSS 和网关认证。

## 验证

- `apps/parent` 的 `flutter analyze`、`flutter test` 全绿。
- debug APK 构建成功。
- 8790 健康检查、8780 状态接口和智能屏 WS 可达。

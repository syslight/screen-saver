# 家庭人物身份确认闭环

## 目标

让家长在现有智能屏 Web 控制台中查看人脸聚类代表照片，并把内部聚类 ID 确认为家庭关系称谓。相册说明只消费家长已确认的称谓，不保存姓名，不允许模型猜测身份。

## 实现范围

1. `PhotoIndexService` 提供人物档案分页查询、确认和撤销能力；计算节点写共享 SQLite，展示节点保留 HTTP 后端兼容能力。
2. 控制服务器提供人物档案 GET/POST 接口，限制分页参数及预置关系称谓，拒绝自由文本和不存在的聚类。
3. Web 控制台提供“待确认 / 已确认”视图、最多 3 张人脸裁剪预览、关系选择、确认和撤销操作；裁剪保留人脸周围环境，避免合影中指代不清。
4. 现有 `/api/index/description` 无需改协议：确认结果写入 `person_profiles` 后，会立即进入照片故事的 `identities` 字段。

## 边界与风险

- 同一个人可能被人脸模型拆成多个聚类；允许多个聚类确认成相同称谓，以便家长逐步修正。
- 本阶段不做人脸聚类合并，也不上传姓名、声纹或人脸原始资料。
- 8780 控制台当前没有独立登录认证，只能用于可信家庭局域网，不得映射到公网。
- 代表照片通过现有照片字节接口加载；已隐藏照片不作为代表样本。

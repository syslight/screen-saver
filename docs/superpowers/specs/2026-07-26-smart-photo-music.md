# 智能相册配乐规格

## 目标

智能屏播放照片时提供不过度打扰的轻音乐，并允许在智能屏和家长 Android App 上独立控制音乐。配乐以人物、人生阶段、地点、事件和照片说明为依据；一段故事连续使用同一音乐主题，避免每张照片都切歌。

## 已确认产品规则

- 音乐与 TTS 使用独立音量，默认音乐音量 55%。
- 音乐默认开启；22:00–08:00 自动静音。
- TTS 播报时音乐自动压低到目标音量的 15%，播报结束后平滑恢复。
- 故事段落至少持续 10 分钟；主题变化采用约 3 秒淡入淡出。
- 第一阶段使用真实授权音乐和本地音乐目录自动匹配；Agent 负责搜索与情境推荐，但入库前必须通过许可证白名单并保存署名信息。
- Kimi/GLM 只负责照片理解和情境分类，不负责生成音乐音频。

## 音乐主题

- 温暖日常
- 童年成长
- 旅行远方
- 岁月回忆
- 欢乐相聚
- 宁静风景

照片说明中的家庭身份、拍摄时间、地点和文字描述共同决定主题。没有足够信息时安全回退为“温暖日常”。

## 本地音乐目录

默认目录为应用支持目录下的 `music/`。用户可按“温暖、童年、旅行、回忆、欢聚、宁静”建立子目录并放入 MP3/WAV/OGG/M4A/FLAC 文件；真实授权音乐和用户音乐优先。每首在线曲目保存作者、来源页、下载地址、许可证和署名；曲库缺失时才使用 SoundFont/WAV 离线兜底。

## C/S 边界

- x86 compute 节点保存并广播音乐开关、静音和音量状态，不输出音乐。
- RK3588/Android display 节点根据当前实际照片选择音乐并输出声音。
- display 通过 compute 的 `/ws` 同步家长指令；屏幕本地操作也回传 compute，使所有家长端收到一致状态。
- 自定义音乐首期存放在实际播放节点；未来音乐生成服务在 compute 生成后需增加受控媒体分发接口。

## 控制协议

新增命令：`set_music_enabled`、`set_music_muted`、`set_music_volume`。新增状态：`musicEnabled`、`musicMuted`、`musicVolume`、`musicTitle`、`musicMood`、`musicQuiet`。

## 非目标

- 本阶段不调用第三方音乐生成服务。
- 本阶段不上传原始家庭照片到音乐服务。
- 本阶段不做逐张照片切歌，也不尝试生成带歌词歌曲。
